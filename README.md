# Java Check - ระบบตรวจงานอัตโนมัติด้วย AI

แอปพลิเคชันเว็บสำหรับตรวจคำตอบของนักศึกษาจากไฟล์เอกสาร (PDF หรือ DOCX) โดยทำงานเชื่อมต่อกับโมเดล AI ผ่าน API เพื่อให้คะแนนและสรุปข้อผิดพลาดโดยอัตโนมัติ

## 🛠️ เครื่องมือที่จำเป็น (Prerequisites)

ก่อนที่จะเริ่มติดตั้งและใช้งานโปรเจกต์นี้ ตรวจสอบให้แน่ใจว่าเครื่องของคุณได้ติดตั้งเครื่องมือเหล่านี้แล้ว:
1. **[Node.js](https://nodejs.org/en/download/)** (เวอร์ชัน 16.x หรือใหม่กว่า)
2. **Git** (สำหรับโคลนโปรเจกต์)

## 📦 วิธีการติดตั้งหลังจาก Git Clone

เมื่อทำการโคลนโปรเจกต์ลงมาที่เครื่องแล้ว ให้ทำตามขั้นตอนดังนี้:

1. เปิด Terminal หรือ Command Prompt แล้วเข้าไปที่โฟลเดอร์ของโปรเจกต์:
   ```bash
   cd Java_Check
   ```

2. ติดตั้ง Dependencies ทั้งหมดที่จำเป็นด้วย npm:
   ```bash
   npm install
   ```
   *(คำสั่งนี้จะทำการอ่านไฟล์ `package.json` และติดตั้งโมดูลที่จำเป็น เช่น `express`, `axios`, `pdf-parse`, `mammoth`, `multer` และอื่นๆ)*

## 🚀 วิธีการรันโปรเจกต์และใช้งาน

โปรเจกต์นี้มีคำสั่งสำหรับรัน 2 แบบ:

**แบบที่ 1: รันโหมดนักพัฒนา (Developer Mode)** แนะนำ!
โหมดนี้จะใช้ `nodemon` ซึ่งจะรีสตาร์ทเซิร์ฟเวอร์ให้อัตโนมัติเมื่อมีการแก้ไขไฟล์
```bash
npm run dev
```

**แบบที่ 2: รันโหมดปกติ**
```bash
node server.js
```

### การเข้าใช้งาน:
1. เมื่อเซิร์ฟเวอร์รันสำเร็จ จะมีข้อความแสดงว่า `Server is running on http://localhost:3000`
2. เปิดเว็บเบราว์เซอร์ แล้วเข้าไปที่: **[http://localhost:3000](http://localhost:3000)**
3. จะพบหน้าจอสำหรับอัปโหลดไฟล์
4. **ลากไฟล์** หรือ **คลิกอัปโหลด** ไฟล์เอกสาร (.pdf หรือ .docx) ของนักศึกษา
5. กดปุ่ม **เริ่มตรวจงาน** แล้วรอให้ AI ประมวลผลและส่งผลลัพธ์กลับมา

## ⚙️ การตั้งค่าเพิ่มเติม (Configuration)

หากคุณต้องการเปลี่ยนที่อยู่ของ AI Server หรือตั้งค่าอื่นๆ สามารถแก้ไขได้ในไฟล์ `server.js` หรือ `test.js`:

- **API URL ของ AI:**
  ที่บรรทัด 21-22 ของไฟล์ `server.js` 
  ```javascript
  const BASE_URL = 'http://10.80.39.41:11941';
  ```
- **ชื่อโมเดล AI:**
  ที่บรรทัด 24 ของไฟล์ `server.js`
  ```javascript
  const MODEL_NAME = 'qwen3.6:27b';
  ```
- **พอร์ตการรันเว็บ:**
  เซิร์ฟเวอร์จะรันที่พอร์ต `3000` เป็นค่าเริ่มต้น แต่สามารถปรับเปลี่ยนได้ผ่าน Environment Variable `PORT`
