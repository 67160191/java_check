# 📝 Java Check - AI Auto-Grading System

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Node.js](https://img.shields.io/badge/node-%3E%3D%2016.x-brightgreen.svg)
![Express.js](https://img.shields.io/badge/express-4.x-lightgrey.svg)

**Java Check** คือแอปพลิเคชันเว็บที่ช่วยอาจารย์หรือผู้สอนในการ **ตรวจคำตอบของนักศึกษาอัตโนมัติ** โดยรองรับการอ่านไฟล์เอกสาร (PDF และ DOCX) และทำงานร่วมกับโมเดล AI (Qwen) ผ่าน API เพื่อประมวลผล ให้คะแนน และสรุปข้อผิดพลาดได้อย่างรวดเร็วและแม่นยำ

---

## ✨ ฟีเจอร์หลัก (Key Features)

- 📄 **รองรับหลายนามสกุลไฟล์:** สามารถอ่านและดึงข้อความจากไฟล์ `.pdf` และ `.docx` ได้โดยตรง
- 🤖 **ประมวลผลด้วย AI:** ขับเคลื่อนโดยโมเดล Large Language Model (เช่น `qwen3.6:27b`) เพื่อวิเคราะห์ความถูกต้องของคำตอบ
- 📊 **ให้คะแนนและสรุปผลแบบเจาะจง:** AI สามารถให้คะแนน สรุปภาพรวม และเจาะจงข้อผิดพลาดพร้อมคำอธิบายเป็นภาษาไทย
- 💻 **หน้าเว็บใช้งานง่าย:** มีหน้าอินเทอร์เฟซสำหรับอัปโหลดไฟล์ที่ใช้งานง่ายแบบ Drag & Drop
- ⚡ **สถาปัตยกรรมที่เบาและเร็ว:** พัฒนาด้วย Node.js และ Express.js

---

## 🛠️ เครื่องมือที่จำเป็น (Prerequisites)

ก่อนเริ่มต้นใช้งาน โปรดตรวจสอบให้แน่ใจว่าเครื่องของคุณมีซอฟต์แวร์เหล่านี้:
- **[Node.js](https://nodejs.org/en/download/)** (เวอร์ชัน 16.x ขึ้นไป)
- **Git** (สำหรับโคลนโปรเจกต์)
- **AI API Server:** ต้องมีเซิร์ฟเวอร์ AI (เช่น Ollama หรือ API ที่รองรับโครงสร้างแบบเดียวกัน) ซึ่งระบบสามารถเชื่อมต่อถึงได้

---

## 📦 การติดตั้ง (Installation)

1. **โคลนโปรเจกต์ลงมาที่เครื่อง:**
   ```bash
   git clone <repository-url>
   cd Java_Check
   ```

2. **ติดตั้ง Dependencies:**
   ระบบจะทำการติดตั้งไลบรารีที่จำเป็น เช่น `express`, `axios`, `pdf-parse`, `mammoth`, และ `multer`
   ```bash
   npm install
   ```

---

## 🚀 การรันโปรเจกต์ (Getting Started)

คุณสามารถเลือกรันโปรเจกต์ได้ 2 โหมด:

### โหมดนักพัฒนา (Developer Mode) 🌟 แนะนำ
ระบบจะใช้ `nodemon` เพื่อรีสตาร์ทเซิร์ฟเวอร์โดยอัตโนมัติเมื่อมีการแก้ไขโค้ด
```bash
npm run dev
```

### โหมดปกติ (Production Mode)
```bash
node server.js
```

### 🎯 วิธีการใช้งาน
1. เมื่อเซิร์ฟเวอร์รันสำเร็จ จะปรากฏข้อความ `Server is running on http://localhost:3000`
2. เปิดเว็บเบราว์เซอร์ไปที่: **[http://localhost:3000](http://localhost:3000)**
3. **ลากไฟล์** หรือคลิกที่พื้นที่อัปโหลด เพื่อเลือกไฟล์เอกสารคำตอบของนักศึกษา
4. กดปุ่ม **เริ่มตรวจงาน** 
5. รอระบบประมวลผล และแสดงผลลัพธ์การให้คะแนนพร้อมคำอธิบาย

## ⚙️ การตั้งค่าเพิ่มเติม (Configuration)

คุณสามารถปรับแต่งการเชื่อมต่อ AI หรือตั้งค่าพอร์ตได้ในไฟล์ `server.js` (สำหรับตัวเว็บหลัก) หรือ `test.js` (สำหรับการทดสอบแยกส่วน)

| ตัวแปร / ค่าคงที่ | คำอธิบาย | ไฟล์ที่เกี่ยวข้อง |
| :--- | :--- | :--- |
| `BASE_URL` | URL ของเซิร์ฟเวอร์ AI (ค่าเริ่มต้น: `http://10.80.39.41:11941`) | `server.js` (บรรทัด 22) |
| `MODEL_NAME` | ชื่อโมเดล AI ที่ต้องการใช้ (ค่าเริ่มต้น: `qwen3.6:27b`) | `server.js` (บรรทัด 24) |
| `PORT` | พอร์ตสำหรับรันเว็บเซิร์ฟเวอร์ (สามารถตั้งผ่าน Environment Variable ได้) | `server.js` (บรรทัด 12) |
